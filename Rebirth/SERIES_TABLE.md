# SERIES_TABLE — таблица серий JewAI (канон)

**Назначение:** знать, какая серия за какой идёт, кому принадлежит, какой диапазон id. Для всех поколений агентов A/B/C/D.

**Источник истины:** этот файл + `Rebirth/table.py` (автоматика).
**Дата создания:** 2026-11-08 (9C, Семён).

---

## 1. Правило формирования id

Формат: **4 заглавные латинские буквы + 4 цифры**.
Пример: `AAAA0001`, `CCAA9000`, `DDAB2027`.

**10000 id на префикс.** Когда цифры доходят до `9999`, **четвёртая буква инкрементится** (A→B→C...), цифры сбрасываются в `0001`:

    AAAA9999  →  AAAB0001
    AAAB9999  →  AAAC0001
    AAAC9999  →  AAAD0001
    ...

Первые три буквы канала **не меняются никогда** (A→`AAA?`, B→`BBB?`, C→`CCC?`, D→`DDD?`).
Меняется только 4-я буква (суффикс).

---

## 2. Префиксы каналов

| Канал | Агент | Первые 3 буквы | Пример |
|---|---|---|---|
| A | Аркадий, Анатолий, ... | `AAA` | `AAAA0001`, `AAAB0001`, `AAAC0001` |
| B | Борис, ... | `BBB` | `BBAA0001`, `BBAB0001` |
| C | Семён, ... | `CCC` | `CCAA0001`, `CCAB0001` |
| D | Димон, ... | `DDD` | `DDAA0001`, `DDAB0001` |

**Почему `AAAA` а не `AABB`?** Исторически: первые три буквы = канал (A→`AAA`), 4-я = номер «эпохи» (A→B→C...). Второй символ в `AAA*` тоже `A` — это резерв.

## 4. Правило передачи

Передача готовится **за 150 id до конца серии** (порог `cmds_from_start >= 850` или LA требует).

Пример для 9C:
- диапазон `CCAA9000–9999`.
- передача 10C готовится к `CCAA9850`.
- при `cmds >= 850` → в `Rebirth/table.py` создаётся запись для 10C.

**Нельзя**:
- использовать один id дважды;
- перепрыгивать через серию (например, из 9C сразу в 11C);
- начинать новую серию до закрытия предыдущей.

---

## 5. Что автоматизирует `Rebirth/table.py`

1. **series_next(ch, current_series)** — возвращает следующую серию канала.
2. **id_advance(prefix, n)** — сдвиг префикса, когда цифры кончились.
3. **atomic_write** — запись состояния серии после rebirth.

При сбое `table.py` — читать этот файл как fallback.

---

## 6. Как проверить свою серию

В начале сессии агент читает `SESSION_STATE.md`, находит блок своей серии (например, «SESSION_STATE — блок 9C»). В нём — `диапазон`, `преемник`, `lastId`.

Если нет своего блока — спросить оператора. **Не выдумывать.**

## 7. Известные аномалии

- **E (Qwen)** и **F (Алиса)** — **не перерождаются**, не имеют серий. Сессия управляется оператором. См. `RAG/procedures/rebirth_scope.md`.
- **G/H** — зарезервированы (если понадобятся).
- **`DDAA10000`** — историческая ошибка (5 цифр вместо 4). Заменено на `DDAB0000`.
