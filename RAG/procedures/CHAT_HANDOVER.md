# Бэкап старых чатов (handover)

## 1. Зачем

Когда чат переполняется или агент перерождается - старая история в SPA остаётся недоступной из нового чата.

**Правило:** выгрузить старый чат в файл **до** перерождения.

## 2. Метод (scroll-loop, НЕ одноразовый снимок)

**Ошибка (набито):** один `innerText` даёт только видимую часть. Длинная беседа обрезается (4B: v1=1249 строк, v2=6373 строки, разница в 5 раз).

**Правило:** scroll-loop - скроллить, снимать, склеивать, дедуп по строкам.

Реализация - `Tools/export_share.py`:

```
python Tools/export_share.py --cdp 9222 --out logs/A/conversations/4A_share.md
```

Параметры:

- `--cdp <port>` - CDP-порт канала.
- `--out <path>` - путь файла.
- `--step <px>` - шаг скролла (default 400).
- `--max-steps <N>` - максимум шагов (default 200).
- `--timeout <sec>` - таймаут (default 90).

Алгоритм:

1. Изолированный `browser.new_context()` (не контекст панели).
2. Открыть чат по URL.
3. Скролл вверх/вниз с шагом, снимать `innerText`.
4. Дедуп по строкам, склейка.
5. `context.close()` (иначе target closed).
6. Запись в файл.

## 3. Что хранить

| Файл | Что |
|---|---|
| `logs/<CH>/conversations/<series>_share.md` | Полная выгрузка |
| `logs/<CH>/conversations/<series>_digest.md` | Дайджест (1-2 абзаца) |
| `logs/<CH>/conversations/README.md` | Строка с описанием |

## 4. Дайджест (обязательно)

Полная выгрузка - 500-800 КБ, читать целиком дорого.

**Дайджест** - 5-10 ключевых пунктов:

- Что делал агент.
- Что закрыто.
- Что открыто.
- Инциденты и грабли.
- Ссылки на артефакты.

## 5. Когда делать

- **За 150 id до конца серии** (перед rebirth).
- **При переполнении чата** (немедленно).
- **По указанию оператора** (например, «сохрани эту беседу»).

## 6. Куда не смотреть

- Не выгружать **всю** историю за всё время - только текущую сессию.
- Не парсить чужие чаты (только свой канал).

## 7. Восстановление из выгрузки

Если нужен контекст старого чата:

1. Открыть `logs/<CH>/conversations/<series>_share.md`.
2. Прочитать дайджест (быстро).
3. При необходимости - конкретные блоки из share.md (grep по `id:`).
