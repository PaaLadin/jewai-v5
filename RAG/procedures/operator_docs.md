# operator_docs.md - папка оператора

## WHEN
- Оператор дает документ, промт для внешнего ИИ, бриф, задачу.
- Агент ищет: где лежат операторские материалы.
- Нужно понять структуру папки operator/.

## WHO
- Оператор - автор материалов.
- B - куратор RAG, следит за чистотой.

## Структура operator/

- README.md - описание папки.
- inbox.md - активные задачи оператора к агентам.
- journal/YYYY-MM-DD.md - ежедневные записи.
- tasks/<task_id>.md - разбор конкретной задачи.
- replies/YYYY-MM-DD.md - ответы агентов оператору.
- read/ - документы, которые оператор дает агентам
  для чтения и исполнения. Здесь же - готовые промты
  для внешних ИИ (Alice, Qwen, Perplexity).

## Что в operator/read/

- PROMPT_kb_canvas.md - промт для генерации картинки
  "Канбан проектов" в CRT-стиле (автор C, 2026-10-05).

## Правила

- Оператор кладет документ в operator/read/ -> агент читает.
- Агент не удаляет и не перемещает материалы оператора.
- Готовые промты для внешних сервисов - тоже сюда.
- Ссылки на эти файлы - из других RAG-документов.
