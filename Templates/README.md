# Templates

- `project/` - скелет нового проекта (README, ROADMAP.md, TODO.md, src/, docs/, tests/).
- `roadmap/` - шаблоны роадмапа (html + md) для проектов.
- `extension/` - extension v5 (копируется в Profiles/<L>/extension).
- `config.llm.example.json`, `config.mail.example.json` - примеры конфигов.

Инсталлятор копирует `project/` и `roadmap/` в развёрнутую копию автоматически.
