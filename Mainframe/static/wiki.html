JewAI v5 — краткая вики

Для неопытного пользователя. Без технических деталей.

Что такое JewAI

JewAI — это мост между браузерным чатом с ИИ (DeepSeek, Qwen, Alice) и твоим компьютером. Ты пишешь агенту в чат задачу, он оформляет её как блок команд, а JewAI выполняет этот блок у тебя на диске и присылает агенту отчёт — что получилось.

Каждый агент живёт в своём отдельном профиле Chrome. 6 агентов = 6 окон Chrome, у каждого свой логин, свой чат, своя история. Они не мешают друг другу.

Каналы и агенты

Агенты обозначаются буквами A, B, C, … (до J — до 10 агентов). У каждого:

  • свой порт агента (обычно 8680, 8681, …) — панель общается с агентом;
  • свой CDP-порт (9122, 9123, …) — JewAI управляет браузером;
  • свой профиль Chrome в C:/JewAI_v5/Profiles/<буква>/chrome/;
  • своя папка логов в Profiles/<буква>/logs/.
Совет: имена агентов задаются при установке. Если забыл какое — смотри Profiles/<буква>/config/config.json, поле name.

Как залогиниться в чат

  1. Открой нужное окно Chrome (его запускает JewAI при первом старте).
  2. В адресной строке — chat.deepseek.com (или chat.qwen.ai / alice.yandex.ru).
  3. Войди в свой аккаунт.
  4. Правый клик по вкладке → «Закрепить».
Не логинь сам Chrome в Google-аккаунт. Достаточно логина в сам чат. Куки и сессия сохранятся в профиле Chrome этого агента и переживут перезапуск. Google-логин только добавит лишние сервисы и риск смешать куки разных агентов.

Панель агента (боковая)

В каждом окне Chrome есть иконка JewAI Agent Bridge. Клик по ней открывает боковую панель с лампами и кнопками.

ЭлементЧто делает
DON'T / WALKСветофор. WALK — мост работает. DON'T — что-то не так (CDP не отвечает / пауза).
CDPЗелёная = Chrome отвечает. Красная = Chrome не запущен или упал.
WATCHDOGЗелёная = сторожевой таймер включён. Тумблер рядом — вкл/выкл.
RECOVERYЗелёная = восстановление включено (если панель зависнет, попробует перезагрузить).
PAUSEКнопка pause/play. Пауза останавливает отправку команд агенту — удобно, когда ты сам пишешь ему в чат.
REBOOTПерезапускает мост канала (Bridge/run.py). Chrome не трогает.
SELF-TESTПроверка: ping, token, root, config, ledger, svc_state. Все OK — зелёная плашка.
PINGПроверка связи с агентом. В логе появится ответ.

Mainframe (панель управления)

Открывается по адресу http://127.0.0.1:8670/. Показывает все каналы сразу: агенты, Chrome, DoH-прокси, mail-bot, rebirth. Кнопки СТАРТ / СТОП / РЕБУТ для каждого блока. Тут же общий чат (broadcast) и чат по каналам.

Mainframe — это обзор. Подробная работа — в боковых панелях агентов.

Перерождение (rebirth)

Когда чат агента переполняется, JewAI «перерождает» агента: открывает новый чат, отправляет туда промт активации, обновляет таблицу серий. Старый чат остаётся в истории, новый агент продолжает в новом.

Простыми словами: агент переезжает в новый чат, сохраняя знания через RAG (файлы на диске).

Порог: 850 команд в текущей серии. При достижении JewAI готовит передачу: HANDOVER, PROMPT новичку, TODO.

Что делать, если что-то сломалось

Красная лампа CDP. Chrome не запущен или упал. Mainframe → кнопка СТАРТ на блоке chrome:<буква>.
Красные WATCHDOG / RECOVERY. Сервисы не запущены. В боковой панели включи тумблеры.
SELF-TEST показывает FAIL. Посмотри какой пункт упал. Частые: token (проверь .agent_token в корне), config (переустанови агента), ledger (директория логов не writable).
Панель показывает UNKNOWN или ?. Нажми PING. Проверь порт агента в поле URL — должен быть твой (например 8681). Если чужой — введи правильный, PING.
В чате «Stopped» (DeepSeek). Content-script автоматически нажимает regenerate, если оператор не печатает. Если не сработало — открой чат, нажми regenerate вручную.

Правило: не удаляй Profiles/<L>/chrome/ руками — потеряешь логин. Если нужно сбросить — закрой Chrome, переименуй папку в chrome.bak, перезапусти launcher.
